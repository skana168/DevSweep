# 使用 GPUI Kit 完整迁移并重新设计 UI

DevSweep 将 UI 完整迁移到 GPUI Kit，保留现有产品能力与持久化数据兼容，同时允许重新设计布局和交互，而非仅逐控件替换 egui。用户于 2026-11-05 确认，以原生桌面体验、清晰的信息层级和高效键盘操作为目标，遵循已安装的 GPUI Kit Design Guides 与 Coding Guides。

这意味着承担 UI 状态、焦点、异步反馈和交互测试的迁移成本，以采用 GPUI Kit 的组件与桌面交互体系。

用户确认继续以 macOS、Windows 为同等验收平台，本轮不扩展 Linux 产品支持。开发期间保留 egui 作为功能对照，GPUI 全部验收后替换默认前端，最终只维护一个前端。保留现有清理预览、确认、执行前重新检查，以及中止、失败反馈和任务排队的安全语义。

本决策替代 ADR-0002 的主题与字体策略：保留应用品牌资产，采用 GPUI Kit 的主题与组件几何，并重新制定平台字体规范。GPUI 前端统一使用 Kit 自带图标，迁移期间 egui 前端继续使用 egui_icons，以保持每个前端的图标体系一致。
