# 使用 GPUI Kit 还原参考窗口

Status: accepted

以用户提供的暖白橙色清理窗口取代 ADR 0002 的 ArtCraft 视觉约定；UI 迁移至 GPUI Kit，扫描、规则、清理计划和执行模块继续复用。接受框架迁移成本，以取得原生 macOS 窗口骨架和参考图布局。macOS 是本轮视觉验收平台，其余平台不纳入本轮验收。

正式界面使用本机真实数据；独立样例模式提供固定截图数据且禁止执行清理。截图中超出现有能力的入口显示未实现提示，全局缓存不冒称系统缓存。平台 UI 字体用于还原截图的中文比例。图标沿用 egui_icons 的 Material Symbols 字形，字体作为资源加载到 GPUI，避免依赖 egui 绘制。

为保留用户要求的参考图视觉，圆角、暖色、固定比例和选中态以截图为准。新界面固定使用参考图的中文浅色视觉；旧的主题与语言配置保留在配置文件中，尚未接入 GPUI 展示。详见 [GPUI 界面](../gpui-ui.md)。
