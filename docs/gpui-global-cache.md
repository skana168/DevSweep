# GPUI 全局缓存（票据 06 / 07）

独立演示入口：

```sh
cargo run --bin devsweep-gpui-cache --features gpui --locked
```

入口读取既有 `Config`（语言、主题、窗口尺寸和扫描根），采用 Kit facade、Kit 图标和原生窗口装饰。它不写配置；设置仍由票据 01 的入口编辑，下次启动演示窗口生效。默认 egui 入口不变。全局缓存选择现可进入清理计划确认与后台执行；主窗口也提供相同流程。

## 主窗口集成

02 的 SettingsApp 主壳已接入全局缓存导航，在全局缓存页首次激活时创建并保留独立实体：

```rust
let caches = cx.new(|cx| {
    GlobalCacheView::new(&config, project_paths, window, cx)
});
// 在已有 Kit Root 内的内容区域挂载，使用 flex_1/min_h_0/min_w_0。
// 父视图 render: .child(caches.clone())
```

`GlobalCacheView` 不依赖 SettingsApp。`new` 启动后台工作并将焦点放到首行；不要在 render 中重建实体。`project_paths` 应来自当前项目工作区；扫描根、项目集合变化时，应重新创建缓存实体，让 Go 保护上下文与工作区一致。已有确认会失效；正在执行时请求中止并保留原实体到操作结束，继续呈现结果。用户重新打开全局缓存页后再以当前上下文测量，不能再次提交旧实体。测量任务随实体释放取消，不会把旧结果写到新实体。保留实体在导航切换间可保留选择草稿。语言变更调用 `set_language(language, cx)`；主题通过 Kit 全局主题传播。

鼠标 Checkbox、Tab/Space、上下方向键、Home/End 可选择和导航；方向键自动将目标行滚入可见区域。选择与焦点分开。路径截断后可使用可聚焦的“复制路径”按钮取得完整路径。所有体积结果完成前显示测量状态，缺失、不可读和非目录路径显示原因并禁止勾选。正常测量后的非危险条目默认选择；危险项（Go module、Cargo registry）必须主动选择。

分组和顺序来自固定 `cache::builtin_caches`，静态路径来自 `cache::entries`；Windows 不展示不适用的 DerivedData。Go 条目调用 `go_cache::discover`，保留扫描根、项目和其它缓存保护以及原错误分类。普通缓存使用现有 `size::dir_size`（不跟随后代链接；根路径链接沿用该 API 的遍历行为）；根目录读取失败有明确反馈，但与既有测量 API 一样，子目录遍历错误会被跳过，体积仍为估算。进度计数是已返回结果数 / 固定条目数，包含失败结果，不是模拟百分比。

`selection()` 读取固定条目 ID 和所选字节汇总，`go_snapshot()` 读取发现时快照。选择草稿不是清理授权。确认在后台按固定 ID 构建计划，展示范围、路径、体积、风险及 Skip；默认采用 Config 的删除方式，Direct 明确不可恢复。只有确认中的清理按钮授权执行；主壳的 Command/Control+Shift+Backspace 也只能进入确认。

普通条目在确认与执行前均调用 `cache::plan`，同时要求解析路径与已测量/已确认路径一致。Go 使用原 `GoCacheSnapshot::plan` 与 `GoCacheClean::execute` 重查询；Go module 保留只读依赖处理，不使用普通目录删除替代。视图路径从不直接形成任意删除计划。

执行在独立工作线程逐个处理缓存条目，前台消费真实完成结果；当前缓存操作继续遵循既有业务的中止边界。界面区分已请求中止和已停止，不使用项目中止文案。确认与执行期间锁定选择、阻止重复提交和并发项目清理；视图销毁请求中止，断连释放界面锁并保留已收到的结果。成功项显示已清理与 0 B，Freed bytes 来自原报告中的计划时体积估算，不重新测量。计划拒绝和执行失败分开呈现；Go 重检失败显示具体原因并回写新快照，失败详情可复制，关闭对话框由 Kit Root 恢复焦点。

## 验证边界

UI integration tests 使用生产实体、真实 Kit 控件、临时文件系统及正常鼠标/键盘事件；不会直接调用选择 handler。现有公开业务测试验证双平台固定路径、分组和 Go 保护。自动化的无头窗口不等于原生平台视觉验收。主壳导航、设置同步、选择保持和清理快捷键有无头集成测试；临时 HOME 子进程覆盖真实 Direct 删除、权限失败/重试、执行前路径拒绝、Go 中止/路径变化及只读 module 清理。删除测试只操作隔离临时夹具。Windows 构建/运行、macOS 原生目测、系统 Trash、真实长目录响应与系统剪贴板仍由票据 08 补证。
