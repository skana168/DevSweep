# GPUI 界面

主程序使用 GPUI Kit。macOS 是当前截图还原与窗口行为的验收平台。

```sh
cargo run
cargo run -- --demo
cargo run -- --demo-tools     # 开发工具参考图样例
```

目录选择使用 GPUI 的异步平台接口；取消不会改变扫描根，重复选择不会重复添加。

正式模式读取现有配置，使用扫描根发现项目，复用原有规则、安全检查与清理执行。顶部扫描菜单提供项目搜索与扫描根设置入口。“重新扫描”保留 Refresh 的既有语义：保留已测量体积和勾选。

“开发工具”按参考图展示工具清理类型，未实现项不参与真实统计与清理；其它已有全局缓存保留在“其他开发工具缓存”折叠组中。完整 Cargo registry 不套用截图两个 Cargo 类型。暂未实现清单见 [RANDMAP.md](../RANDMAP.md)。

“Xcode 数据”仅展示 DerivedData，“项目构建产物”展示项目内清理项。其它尚未接入的分类、导航和项目类型点击后显示提示。Go 缓存使用工具链查询并在执行前重新查询；每次单独清理一项。

分类头显示当前分类已选体积，窗口底栏累计全部分类的清理选择，窗口“清理”作用于这份全局选择。分类全选与推荐只修改当前分类，切换分类保留勾选。

清理先显示路径预览和风险说明，确认后复查，只执行确认范围内仍满足规则的路径。删除方式在设置中选择，默认移入废纸篓。执行中可以中止，失败会保留原因。

`--demo` 使用固定截图样例，不扫描本机、不执行清理、不写配置。它用于核对视觉结构，包含明确的样例模式标识。默认窗口是参考窗口本体的 75%（1437×899 逻辑像素），最小 1080×680；用户窗口尺寸会保存。桌面壁纸不属于应用内容。

## 验证

```sh
cargo test --lib --tests -- --test-threads=1
cargo clippy --bin devsweep --test gpui_window -- -D warnings
cargo test --test gpui_window
```

macOS 的 `gpui_window` 使用真实 Metal 离屏渲染器和生产视图，验证未实现提示、Escape、样例清理保护、侧栏折叠、设置入口，以及默认、最小和参考尺寸下的清理按钮可见性。画面输出到 `.scratch/gpui-ui/gpui-render.png`，开发工具画面输出到 `.scratch/developer-tools-ui/developer-tools.png`。开发工具验证另覆盖部分选择、全选/取消、风险行提示、路径展开和小窗口列表滚动。其它平台跳过此 Metal 验证目标。

离屏画面不包含 macOS 窗口按钮和系统阴影。原生窗口配置保留透明标题栏、原生红黄绿按钮、标题拖动和 Command-Q；这些仍需在可访问的原生窗口中人工验收。当前自动化工具对预览应用返回 `cgWindowNotFound`，因此尚不能声称完成原生窗口的逐像素验收。

设计决策见 [ADR 0003](adr/0003-gpui-reference-window.md)。图标来源及 Godot 例外记录在根 `NOTICE` 中。
