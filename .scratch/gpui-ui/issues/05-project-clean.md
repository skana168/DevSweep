# 05: 项目清理完整流程

**What to build:** 将跨项目选择转为可审阅的清理计划，经确认后执行，持续反馈进度、中止与结果，并能查看复制失败详情。

**Blocked by:** 04 — 项目清理项选择与批量汇总

**Status:** ready-for-agent

- [ ] 确认界面展示 Delete plan、删除方式、已选体积及 Skip 原因；Trash 默认，Direct 明确不可恢复后果。
- [ ] 确认锁定草稿，执行前重新生成计划并应用既有安全检查；鼠标及快捷键均不能绕过确认。
- [ ] 后台执行保持界面响应，防止重复提交，保持既有刷新、测量排队及解锁语义。
- [ ] 明确区分请求中止与已经停止，保留以项目为单位的中止边界；断连和完成结果正确结束状态。
- [ ] 结果区分 Skip 与 Failure，Freed bytes 按既有估算语义呈现，失败详情可查看、复制并继续后续操作。
- [ ] 保留业务回归测试，使用 GPUI UI integration tests 覆盖确认、取消、执行、中止、失败和焦点恢复。

## 实施约定

遵循已确认的 GPUI UI 迁移规格与 ADR-0003。遇到 GPUI 用法或设计疑问，查阅已安装的 gpui-kit 与 gpui-kit-design-guides skills，并核实当前版本 API。沿用领域词汇表，保持现有安全语义。
