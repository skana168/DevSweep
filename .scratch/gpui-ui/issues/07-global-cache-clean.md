# 07: 全局缓存清理完整流程

**What to build:** 将所选全局缓存接入计划确认、后台清理、中止及结果反馈，沿用项目清理中已验证的呈现模式。

**Blocked by:** 05 — 项目清理完整流程；06 — 全局缓存发现、测量与选择

**Status:** ready-for-agent

- [ ] 确认显示所选缓存、删除方式、范围、体积及风险，不误称为项目 Target 或项目 Rule。
- [ ] 复用既有全局缓存安全检查，执行只能作用于固定缓存清单所解析的路径。
- [ ] 后台执行、防重复提交、中止、完成和失败反馈遵循既有缓存业务语义，不套用不适合缓存的项目执行边界。
- [ ] 失败详情可查看和复制，关闭确认与结果浮层正确恢复焦点。
- [ ] 业务测试及 GPUI UI integration tests 覆盖确认取消、执行、中止、路径拒绝与失败恢复。

## 实施约定

遵循已确认的 GPUI UI 迁移规格与 ADR-0003。遇到 GPUI 用法或设计疑问，查阅已安装的 gpui-kit 与 gpui-kit-design-guides skills，并核实当前版本 API。沿用领域词汇表，保持现有安全语义。
